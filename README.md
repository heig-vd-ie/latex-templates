# Latex
Latex templates for reports and presentations of the institute.

## Beamer Template

Simple and sober presentation following HEIG-VD and HES-SO color code. The example features TIKZ examples, columns, Tables, and lists.

### For confidential presenatations (material under NDA or sensitive content)
In all tex files, there is a variable to check in order to stamp the confidential mark or not

<code>\newif\ifconfidential
\confidentialtrue   % set to \confidentialfalse or \confidentialtrue
</code>

## Short document Template

typically used for laboratory or project data, and for short documents of between 2 and 10 pages. The example features color codes, figures, links and reference tables.
